fix(leave): a sent request showed an old balance as if it were live

A sent leave request read "Days left before this  19": the balance as
it stood when the request was written. On a request already sent it
reads as a live figure the employee cannot act on, and it goes stale
the moment anything else is approved. The balance helps while
choosing dates, so it now shows only on a new request, as "Days
left"; after that, the Requests balance card is the answer.
