fix(pwa): closing a request sheet threw inside the file preview

Owner, 28 Sep 2026: "find the nadi pwa crashes. it was started as
sheet." A crash hunt opened every sheet four times as staff and as an
approver and read the app's own crash reports. One real crash, on
every close of the request sheet (Requests, Time off):

  [diagnostics] vue.render TypeError: Failed to execute
  'createObjectURL' on 'URL': Overload resolution failed.
  at FilePreviewModal ... (onBeforeUnmount)

RequestActionSheet and FileUploaderView keep `selectedFile = {}` until
a file is tapped. FilePreviewModal's `src` was a computed that called
URL.createObjectURL(props.file) whenever there was no file_url — and
its unmount cleanup read `src`, so closing the sheet called it on `{}`.

The source now comes from utils/previewSource.js: a saved attachment
uses its own URL, a real Blob (a picked file) gets one blob URL,
released once when the file changes or the preview goes away, and
anything else has no source. Nothing is made for the placeholder.

After: the same sheets opened and closed 3x each — no errors; a picked
PNG still previews (blob URL, image loaded); the full crash hunt
reports no real errors on any sheet.
