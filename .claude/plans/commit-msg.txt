feat(checkin): the check-in screen shows the site you are actually at

Follow-up to df282a764 (HR can let a person check in at more than one
site). The server now accepts any of a person's sites, but the check-in
screen still measured against the main one — someone standing at their
second site would read "5.5 km from Damansara" and a warning, then be
accepted anyway.

The screen now picks the same site the server judges by
(utils/nearestSite.js, mirroring hrms/utils/geofence.evaluate_sites):
a free site or one they are inside, else the nearest. It uses the
other_sites the map endpoint already returns. With one site, or before
a position arrives, it is exactly the main site as before.

The CheckInPanel location harness binds the component's imports by
hand; nearestSite is added there.
