Strict-mode blocks aren't currently persisted (the check-in never inserts), so to populate this report we'd need either a new lightweight Geofence Reject Log doctype written from the override, or mining the existing server log. The mock assumes the doctype — much cheaper to query than parsing logs. "Misconfig" rows (last) surface Shift Assignments where strict mode is on but the assignment has no shift_location — admins want these visible because they're silent productivity blockers.
