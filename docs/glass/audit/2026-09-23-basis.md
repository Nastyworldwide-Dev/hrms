# The basis — what every finding is judged against

23 Sep 2026. Every finding in the audit cites **one rule ID** from this file. A finding with no rule ID is not a finding.

Rules are quoted or tightly paraphrased from the source named. Where a number is given (a size, a time, a ratio), it is the source's number, not ours.

---

## A. Accessibility — WCAG 2.2, level AA (W3C Recommendation, 5 Oct 2023)
Source: https://www.w3.org/TR/WCAG22/

| ID | Rule (success criterion) |
|---|---|
| A-1.1.1 | Non-text content has a text alternative (icons that carry meaning have a name) |
| A-1.3.1 | Info and relationships: structure (headings, lists, groups, labels) is in the markup, not only visual |
| A-1.3.4 | Orientation: content is not restricted to one orientation **unless essential** |
| A-1.4.1 | Use of colour: colour is not the only way to convey information |
| A-1.4.3 | Contrast (minimum): text ≥ 4.5:1, large text ≥ 3:1 |
| A-1.4.4 | Resize text: text can be enlarged to 200% without loss of content or function |
| A-1.4.10 | Reflow: no two-way scrolling at 320 CSS px wide; content is not lost |
| A-1.4.11 | Non-text contrast: controls and meaningful graphics ≥ 3:1 |
| A-1.4.12 | Text spacing: no loss of content when line/letter/word spacing is increased |
| A-1.4.13 | Content on hover or focus: dismissible, hoverable, persistent |
| A-2.1.1 | Keyboard: every function works from a keyboard |
| A-2.1.2 | No keyboard trap |
| A-2.4.3 | Focus order preserves meaning |
| A-2.4.6 | Headings and labels describe topic or purpose |
| A-2.4.7 | Focus visible |
| A-2.4.11 | Focus not obscured (minimum): focused item not fully hidden by sticky content (e.g. a floating tab bar) |
| A-2.5.3 | Label in name: the visible label is part of the accessible name |
| A-2.5.8 | Target size (minimum): 24 × 24 CSS px, or enough spacing |
| A-3.2.3 | Consistent navigation: repeated navigation appears in the same order |
| A-3.2.4 | Consistent identification: same function, same name |
| A-3.3.1 | Error identification: the error is described in text |
| A-3.3.2 | Labels or instructions for input |
| A-3.3.7 | Redundant entry: information already given is not asked again in the same process |
| A-4.1.2 | Name, role, value: every control exposes them |
| A-4.1.3 | Status messages: announced without moving focus |
| A-2.3.3 | Animation from interactions can be disabled (AAA, adopted by this project, revamp §19) |

Also: **WAI-ARIA Authoring Practices Guide** (https://www.w3.org/WAI/ARIA/apg/). Dialog (modal) pattern: focus moves into the dialog, Escape closes it, focus returns to the opener.

## B. Usability — Nielsen Norman Group
Source: https://www.nngroup.com/articles/ten-usability-heuristics/ (Nielsen, 1994, updated 2024)

| ID | Heuristic |
|---|---|
| H1 | Visibility of system status |
| H2 | Match between system and the real world (the user's words, not the system's) |
| H3 | User control and freedom (a clearly marked exit) |
| H4 | Consistency and standards (internal and platform) |
| H5 | Error prevention |
| H6 | Recognition rather than recall |
| H7 | Flexibility and efficiency of use |
| H8 | Aesthetic and minimalist design ("every extra unit of information competes with the relevant units") |
| H9 | Help users recognise, diagnose and recover from errors |
| H10 | Help and documentation |

NN/g articles used as rules:
- **NG-PD** Progressive disclosure: show the few important options, and defer the rest to one step away. https://www.nngroup.com/articles/progressive-disclosure/
- **NG-EMPTY** Empty states must say what is missing and offer the way forward. https://www.nngroup.com/articles/empty-state-interface-design/
- **NG-MODAL** Modal dialogs only for short, focused tasks that need an answer before going on. https://www.nngroup.com/articles/modal-nonmodal-dialog/
- **NG-CAPS** All-caps text slows reading. Use sentence case for UI text. https://www.nngroup.com/articles/all-caps/
- **NG-ANIM** UI animation: 100–500 ms, shorter for frequent actions. https://www.nngroup.com/articles/animation-duration/

## C. Laws of UX (Yablonski, lawsofux.com)

| ID | Law |
|---|---|
| L-FITTS | Time to a target depends on its size and distance. Main actions are big and in thumb reach. |
| L-HICK | Decision time grows with the number of choices |
| L-JAKOB | People expect your app to work like the others they use |

| ID | Rule | Source |
|---|---|---|

| HIG-SHEET | A sheet is for a scoped task. Swipe down or Cancel dismisses it. | Apple HIG, *Sheets* |

| M3-CASE | Sentence case for buttons, labels, titles | Material 3, *Writing* |

## H. Anti-"AI slop" (what makes a UI look generated, not designed)

Each rule is a named practice from the sources above. None is taste.

| ID | Slop sign | Basis |
|---|---|---|
| S-DECO | Decoration with no job (gradient blobs, glows, ornament) | H8; owner ruling 23 Sep ("no blob") |
| S-EMOJI | Emoji in interface text | W-PLAIN; H8 |
| S-HERO | Greeting or hero block that holds no information or action | H8; NG-PD |
| S-EYEBROW | Small caps labels over every block | NG-CAPS; W-DYS |
| S-ICON | An icon on every row that doesn't tell items apart | H8; A-1.1.1 (a decorative icon is noise to a screen reader) |
| S-STAT | Numbers that lead to no action | H8 |
| S-EXPLAIN | Helper sentences under controls that restate the label | H8; W-PLAIN |
| S-DUP | The same number, action or destination in two places | H4; owner rule "no redundant work" |
| S-TILE | Big tile grids used as a menu | L-HICK; H8 |
| S-FAKE | Invented data, placeholder copy, fake precision ("8.03 h") | H2 |
| S-ARROW | Arrow decoration on buttons that don't navigate | H4 (an arrow promises a new screen) |
| S-CARD | Cards inside cards; a panel for every item | Glass spec §15 (surface budget); H8 |
| S-MOTION | Animation with no meaning (wrong kind, or too long) | M3-MOTION; NG-ANIM |

## Severity scale

| Grade | Meaning |
|---|---|
| **Critical** | Broken behaviour, lost work, wrong data, a WCAG A/AA failure that blocks a task, a security or privacy leak, a live regression |
| **Important** | A rule broken in a way people meet daily: confusion, repetition, extra steps, a slop sign on a main screen |
| **Polish** | A rule broken at the edges: wording, spacing, a rare state |
