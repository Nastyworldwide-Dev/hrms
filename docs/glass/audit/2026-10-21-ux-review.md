## Verdict

The app is in good shape. It has plain words, one main action per screen, grouped lists
with "See all", a visible focus ring and a skip link.

**Main consequence:** when a form is blocked, it explains why in database words. It
names fields the person cannot see or fix ("Expense Approver, Expenses fields are
mandatory").

**Highest-priority fix:** F1 + F2. Route every blocked-Send message through the plain
labels the form already shows, and say what to do next.

### Strengths to keep

- Plain task names: Time off, Fix a day, Goes to, Waiting (**shown**, m_requests.png).
- One primary button per screen; Check in leads Home (**shown**, m_home.png).
- Summary-first lists: "Your last 5" + See all; Notifications fold repeats (**shown**).
- Visible focus: `outline auto 3px` on Home's first control (**shown**, probe log).
- The OT form says why there is nothing to claim, in words (**shown**, m_ot-requests_new.png).

## Flows (staff sends Time off with an empty field)

- **Now:** open the form → tap Send → read "Leave Type, From Date, To Date fields are
  mandatory" by the button → work out which rows those are → fill them → Send.
  That is 5 steps, one of them a translation.
- **Proposed:** open the form → tap Send → each empty row says "Choose a kind of leave" /
  "Pick a date", and the first one gets focus → fill them → Send. 4 steps, no translation.

## Staff with no approver sends an expense

- **Now:** add a line → Send → "Expense Approver … mandatory" → dead end.
- **Proposed:** open the form → banner "No one is set to approve your expenses yet. Ask
  HR." → Send stays disabled, with the reason linked. The dead end is now a named next step.

## Five principles for Nadi

1. **Words on the screen are the only words.** Check: no message names a label that is
   not visible on that screen.
2. **Every dead end names a person or a step.** Check: each blocked state says who fixes it
   (you, your manager, HR).
3. **One fact, one source.** Check: shift, balance and status read the same on every screen
   that shows them.
4. **The main action is a button, not a glyph.** Check: on any empty form, the first action
   is a labelled control ≥44 pt.
5. **Summary first, tap to narrow.** Check: no list longer than 5 without See all; counts
   read as counts.
