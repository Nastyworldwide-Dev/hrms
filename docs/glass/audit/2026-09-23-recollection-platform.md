## 1. Version: Source of Truth
**FAIL** — No single source of truth

- `frontend/package.json:4` — version: **0.0.0** (generic dev placeholder)
- `frontend/vite.config.js:15` — `__APP_BUILD__` stamp (compile-time ISO date, e.g. "2026-09-23 10:44"), injected into bundle
- `hrms/__init__.py:7` — `__version__ = "16.23.0"` (Frappe package version, not PWA)
- `git tag --list` — v1.0.0, v14.x.x series (no nadi/nz-glass specific versioning)
- `frontend/src/views/Profile.vue` — displays `__APP_BUILD__` in "About this app" screen
- `frontend/src/utils/diagnostics.js` — includes `BUILD` constant (same `__APP_BUILD__`)

**Evidence:** version displayed in app UI is build timestamp only; no semver for PWA releases; frontend/package.json is spec placeholder.
