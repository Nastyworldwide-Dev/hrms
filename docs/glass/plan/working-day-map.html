Where they disagree today

Outlet worker: shift rest day Wednesday, company calendar rest day Sunday

OvertimeWed = rest
Absent markingWed = rest
Leave on Wed1 day taken
PayrollWed = work

And the other way round: a Sunday on leave costs 0 days, but Absent marking treats it as a working day.

Rostered by hand, Wednesday left empty

Absent marking skips Wednesday because there is no shift. Leave on Wednesday still costs 1 day, and payroll counts it as a working day.

New staff, no calendar anywhere

Before alpha.26 this was anyone added after setup. Leave is refused, the balance says "None allocated yet", and the monthly sheet shows no rest days. alpha.26 and the monthly-sheet fix cover everyone whose Employee or Company has a calendar.

Leave that spans two calendars

For example, the old calendar ends 31 Dec and the new one starts 1 Jan. Each date is counted against its own calendar. This is correct today and must stay correct.

Calendar edited after a leave was approved

A holiday added later changes the recount of that old leave, so a balance can move after approval. This is how HRMS is designed, not a crash.

What I got wrong last time

I proposed recounting past leave against the calendar saved on each leave record. Since January 2026, HRMS counts each date against the calendar that applies on that date, and a test checks leave that spans two calendars. Recounting against the saved calendar would break that case, so that proposal is withdrawn.

What still holds: when no calendar at all is found for a past leave date, the whole balance fails to load. A narrow fix uses the saved calendar only when nothing else is found. It would land only with a test for the two-calendar case.

Three decisions for you

Decision 1

One rest-day rule for everything?

Overtime and Absent marking already use "the shift's calendar first, then the person's". Using it for leave and payroll too makes everything agree, but it changes pay and balances. This is the biggest change here.

Decision 2

Is a roster gap a day off?

Should leave on a day with no shift cost 0 days? Today it costs 1.

Decision 3

Can an approved leave change later?

Should a holiday added after approval change that leave's day count? Today it can.
